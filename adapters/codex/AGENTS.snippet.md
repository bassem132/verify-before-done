## Verify before done

- Never say done, fixed or passing without evidence from this session gathered after your last edit.
- Run the checks that cover the change (tests, typecheck, lint, build; commands listed above). Read the full output, not just the exit code.
- For UI changes, run the app and do the action yourself, including RTL if the app supports Arabic.
- Report: what you ran, the key output, and what you couldn't check.
- Never delete, skip or loosen a test to make it pass without telling me.
- Don't commit or open a PR while checks are failing unless I say so.
